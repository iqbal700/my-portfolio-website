# 🚀 Project Name (Portfolio website)

A modern, fully responsive web application built with **Next.js**, **Tailwind CSS**, and **DaisyUI**. This project features a clean user interface, dynamic components, smooth animations, and a fully functional contact form.

## 🌟 Features

- **Modern UI/UX:** Styled using Tailwind CSS and DaisyUI.
- **Contact Form:** Integrated with **EmailJS** to receive user messages directly in the inbox.
- **Instant Notifications:** Uses **React-Toastify** for professional success and error alerts.
- **Security:** API keys and credentials are secured using Environment Variables (`.env`).
- **Animations:** Smooth transitions powered by **Framer Motion** and **Lucide React** icons.

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS & DaisyUI
- **Icons & Animations:** Lucide React & Framer Motion
- **Email Service:** EmailJS
- **Notifications:** React-Toastify
